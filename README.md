# dovesi

Personal site for Pier Luigi Dovesi, built with Vite, React, TypeScript, and Tailwind CSS.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build in `dist/`.
- `npm run lint` runs ESLint.
- `npm test` runs the Vitest suite.

## Notes

- The site defaults to light mode during the day and dark mode at night.
- The background rendering is handled by [`src/components/HoughBackground.tsx`](/Users/pier/other_projects/dovesi/src/components/HoughBackground.tsx).
